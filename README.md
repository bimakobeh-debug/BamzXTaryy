# Proxy BamzXTary

Starter Android project with a purple/pink UI and a GitHub Actions workflow that builds a debug APK.

## Important scope
This is a **demo interface only**. The proxy form saves no network connection and does not implement a real proxy or VPN tunnel. Visual toggles are local UI controls and do not interact with Free Fire. No game injection, anti-cheat bypass, or ban evasion is included.

## Build on GitHub using a phone
1. Upload the contents of this project to a GitHub repository on branch `main`, preserving file paths.
2. Open the repository's **Actions** tab.
3. Select **Android APK Build** and tap **Run workflow** (or push a commit to `main`).
4. Wait for the run to succeed.
5. Open the completed run and download artifact `Proxy-BamzXTary-APK`.
6. Extract the ZIP to get `app-debug.apk`.

The APK is a debug build for testing. It is not signed for Play Store release.
